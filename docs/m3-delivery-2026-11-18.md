# M3 阶段交付（2026-11-18）

> 状态：房间控制面、文件传输、Windows GUI（含 TUN）、wss/DH 挑战、离线直连均已落地并三方测试通过；未做项见 §4。

## 1. 已实现

### 1.1 房间控制面（`f7dabe8`）
- 房间短码（6 位）+ 创建者密码（SHA-256 salted hash）；单房间硬上限 **8**；房间列表（房间号 + 创建者昵称 + 人数/上限）；加入必须密码；房间间信令/中继隔离。
- 验证文件 `ara-server gen-access`：服务器地址 + join token + 服务器公钥 + 自签证书 PEM；token 可吊销。
- `ara-server kick --room/--id`（5s 内生效）；客户端收到 `Kicked` 后停止重连。
- 本地房间快照 `room.json`（退出/断线写，`0600`）；服务端日志按天轮转；旧 M1/M2 协议兼容。

### 1.2 文件传输（`6cc3e5c`）
- 请求/接受/拒绝、64 KiB 分片、offset 断点续传、整文件 SHA-256、路径安全、`transfers.json`（0600）、`Final{ok}` 确认；CLI `send/recv`。

### 1.3 Windows GUI（`bc01011`、`beb884e`）
- `ara-gui`（eframe/egui），`windows_subsystem = "windows"`（无控制台）；房间表单、状态栏、成员列表、日志面板。
- 已接 **TUN**（`tun` + 内嵌 wintun.dll）与 `UiEvent` 控制面；单实例（`single-instance`）；外置 `ara-gui.exe.manifest`（requireAdministrator）。
- 无托盘。

### 1.4 安全（`866bccd`、`2788e89`）
- **wss/TLS**：`gen-access` 生成自签证书（SAN=服务器 host），access 文件带 `cert_pem`；客户端只信任该证书（pin-by-root），信令不再明文。
- **X25519 DH 挑战**：服务端 nonce + 共享密钥证明，防冒用公钥；token 校验；`server.key`/本地状态 0600。

### 1.5 离线直连（`a472cee`）
- `ara ip-connect --peer IP:PORT --peer-key <对方公钥> --peer-vip 10.99.0.3 --vip 10.99.0.2`：不连服务器、不建房间；复用 TUN+WG+UDP/TCP 打洞，手动交换公钥/地址。
- `ara id` 打印本机公钥。
