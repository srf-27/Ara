# 交付文档：GUI 白屏根因修复与流程闭环（2026-11-19）

> 接续 `docs/m3-delivery-2026-11-18.md` 与上一版验收报告。上一版把「GUI 一片空白」误判为 egui GPU 渲染的截图限制；本轮用当前屏幕真实截图定位到**真实产品缺陷并修复**，未再归因为工具限制。

## 0. 结论

GUI 白屏是**真实产品缺陷**，根因是 `ara-gui/Cargo.toml` 关闭了 eframe 默认特性，连带关掉 `default_fonts`，导致 egui 字体表为空、所有文字无法栅格化；且内置字体不含中文。已修复并截图证明中文全部正常渲染。

本轮共修复 **7 个产品缺陷**，新增 **5 项 GUI 能力**，CLI 与服务端各修 1 项。全量编译、`cargo test --workspace`、`clippy -D warnings` 全部通过。GUI 主流程（验证文件载入、WSS/明文自适应、密码掩码、房间列表、错误反馈、单实例、长文本、退出/切换）已用当前屏幕真实鼠标+键盘逐项截图验证。

## 1. 白屏根因（已修复）

| 项 | 内容 |
| --- | --- |
| 现象 | 窗口标题 `Ara` 可见（Windows 绘制），客户区只有布局线和复选框 `✓`，无任何文字 |
| 错误判断（上一版） | 「egui/glow 字体是 GPU 纹理，GDI/DWM 抓不到，与桌面活动无关」 |
| 真正根因 | `eframe = { default-features = false, features=["glow"] }` 关掉了 `default_fonts`。`epaint::FontDefinitions::default()` 在 `not(feature="default_fonts")` 下返回 `Self::empty()`，字体表为空 |
| 证据 | `epaint-0.29.1/src/text/fonts.rs:257-263` 源码；修复前后同法截图对比 |
| 修复 | ① `features` 加 `default_fonts`；② `setup_fonts()` 运行时从 `C:\Windows\Fonts\simhei.ttf` 加载中文字体作为 Proportional/Monospace 回退，支持 `ARA_CJK_FONT` 环境变量覆盖；③ 字体缺失时日志给出提示 |
| 验证 | 截图中文全部可读：服务器/房间号/房间密码/昵称/创建新房间/加入创建/房间列表/成员/文件传输/日志 |

## 2. 本轮修复清单

| # | 严重度 | 问题 | 位置 | 修复 |
| --- | --- | --- | --- | --- |
| 1 | 阻断 | GUI 白屏，全部文字缺失 | `ara-gui/Cargo.toml`、`main.rs` | 开 `default_fonts` + 加载系统中文字体（见 §1） |
| 2 | 高 | GUI 单实例失效，第二次启动出 2 个窗口 | `ara-gui/src/main.rs` | `SingleInstance` 局部 `if let` 块结束即 `Drop` 关闭互斥体；改为 `_instance` 绑定到 `main` 生命周期。验证：第二次启动仍 1 窗口 |
| 3 | 高 | 连接失败/超时后按钮永久禁用，无法重试 | `ara-gui/src/main.rs` | 引入 `Phase{Idle,Connecting,Connected}` 状态机；失败事件复位为 Idle、停止后台 runtime；新增「退出房间」按钮 |
| 4 | 中 | 房间密码明文显示 | `ara-gui/src/main.rs` | `TextEdit::password(true)` + 「显示」复选框切换。截图证明默认掩码 `•••••`、勾选后明文 |
| 5 | 中 | `ara rooms --access` 在 WSS 下报 `invalid HTTP version` | `ara/src/client.rs` | 抽出 `fetch_rooms()` 共享逻辑，按 `cert_pem` 选 `ws://`/`wss://` 并 pin-by-root |
| 6 | 中 | `fetch_rooms` 遇到 access-enabled 服务端的 DH 挑战直接失败 | `ara/src/client.rs` | 补 `Challenge` → `ChallengeReply` 应答（复用 `dh_proof` + `server_pub`）；CLI/GUI 共用 |
| 7 | 中 | `up --room <不存在的码>` 会隐式创建房间 | `ara-server/src/lib.rs` | 新增 `join_existing_room()`，M3 join 路径未知房间直接拒绝；M1/M2 legacy 路径不受影响。实测 `up --room NOPE01` 被拒 |
| 8 | 低 | 启动时加载空房间快照，日志写「本地快照：房间 ，0 位成员」 | `ara-gui/src/main.rs` | 加载时过滤空 `room_code` |
| 9 | 低 | 状态栏错误在用户编辑表单后不清除 | `ara-gui/src/main.rs` | 表单字段 `changed()` 时清除 `status_error` |
| 10 | 低 | CLI `up` 只报「channel closed」，真实错误（如 UDP 端口占用 10048）被吞 | `ara/src/main.rs` | `tokio::spawn` 内打印 client 返回的真实错误 |
