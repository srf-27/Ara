# Ara M3 Windows GUI 设计规范

> 来源：`ui-ux-pro-max`（规则/参数/配色/指南）与 `emilkowalski/skills`（动效与交互 craft）。两者均为 Web/React/Swift 语境，本文只复用其**规则与参数**，在 egui 里手写实现，不引入 Web 栈、不复制仓库进项目。

## 1. 不可妥协项

- 文本对比度 ≥ 4.5:1（大字/非文本 ≥ 3:1）；语义色 token 统一管理，禁止组件内写死颜色。
- 状态不能只靠颜色：连接状态/房间满员/传输失败必须同时有文字 + 图标。
- 所有可交互控件有可见焦点环（2–4px）；图标按钮必须有可访问名（egui `on_hover_text`）。
- 错误提示就近放在相关控件下方，必须含「原因 + 修复 + 恢复动作」。
- 破坏性操作（退出房间、断开、删除传输）先确认；危险按钮与主按钮空间分离。
- 间距用 4/8dp 节奏；正文行高 1.5–1.75；长文本中间截断（不要尾部截断，否则 `…-v12-final.pdf` 全一样）。
- 人数、字节、速度、进度百分比用等宽数字（egui 用 monospace 数字字体），防止跳动。
- 列表 ≥ 50 项启用虚拟化（egui `ScrollArea::show_rows`）。

## 2. 语义色与字体（egui 实现）

- 定义 `Theme { bg, surface, surface_hover, text, text_muted, primary, success, warning, danger, ring }`，亮/暗主题成对维护；深色不是简单反色。
- 房间列表/成员表：行高 40–48px，左侧头像/状态点 `fixed`，中间昵称与房间号 `min-width:0` 可截断，右侧人数/操作 `fixed`。
- 连接状态四态：`已连接`（success）、`连接中`（warning + 旋转环）、`重连中`（warning + 倒计时）、`被踢/失败`（danger + 持久提示）。

## 3. 组件规范

**房间列表**：房间号（等宽）、创建者昵称、`在线/上限`；满房整行置灰且不可点；点击可进房 → 若已在别的房间，弹「将退出当前房间」二次确认（仅此一个语义）；密码错误在密码框下方提示并可重输，不混入确认弹窗。

**密码/确认弹窗**：可见 label + 持久 helper；提供显示/隐藏；允许粘贴；确认按钮在提交期禁用并显示进度；Esc/取消明确可用；模态居中，popover 才从触发点展开。

**传输请求**：显示来源昵称、文件名、大小；接受/拒绝两个动作；60s 倒计时；过期自动关闭并提示。

**传输进度**：确定进度用 `ProgressBar`（linear），不确定用旋转环；>1s 才显示进度；提供暂停/继续/取消；中断必须给出「已取消/失败 + 重试」，不允许进度条无声卡死；字节与速度用等宽数字。

**被踢/封禁**：不可逆事件用持久提示（不自动消失），写明原因与恢复路径（重新导入验证文件/返回列表）；停止自动重连。

**托盘**：显示连接状态与当前房间；菜单项：打开主窗、复制我的 ID、退出房间、退出程序；高频操作（打开窗口）不做动画。

## 4. 动效

- 一律 < 300ms；进入/退出用 ease-out（`cubic-bezier(0.23,1,0.32,1)`），屏内移动 ease-in-out，进度条 linear；**绝不用 ease-in**。
- 退出比进入快（约 60–70%）；按钮按压 `scale(0.97)`，100–160ms。
- 每视图最多 1–2 个动画元素；列表 stagger 30–50ms；快速状态切换必须显式设定最终态（可中断），不依赖动画结束回调。
- 高频动作（托盘开关、刷新列表、键盘触发）**不做动画**。
- 提供「减少动态效果」开关：保留透明度/颜色变化，去掉位移与缩放。

## 5. 最坏数据验收（`break-ui`）

用真实最坏数据逐项过一遍：超长昵称（中/英/emoji）、超长文件名与路径、空房间列表、1 人/8 人房间、单复数（`1 位成员`）、翻译后的长标签、窄窗口（最小 900×600）、高 DPI 200%。

## 6. Skill 使用映射

| Skill | 在本项目中的用途 |
|---|---|
| `ui-ux-pro-max` | 语义色 token、间距/字阶、对比度与无障碍检查、组件反模式 |
| `emil-design-eng` | 组件手感、状态与反馈、边界处理的总原则 |
| `apple-design` | 托盘/弹窗的层次与物理感、克制用动效 |
| `animate` / `improve-animations` / `review-animations` | 动效参数与评审（时长、缓动、可中断） |
| `find-animation-opportunities` / `remove-animations` | 判断哪里该动、哪里必须删 |
| `animation-performance` / `animation-vocabulary` | 性能与术语统一 |
| `gestures` / `mobile-native` | 触控板/手势与桌面手感（仅取适用部分） |
| `pick-ui-library` | 组件选型参考（egui 生态替代品） |
| `break-ui` | 最坏数据清单与 dev-only 切换 |
| `learn-taste` / `prototype` / `ask-emil` | 设计评审与多变体对比 |
| `ask-sonner` | toast/持久通知的交互语义（映射到 egui 提示条） |

## 7. Windows 集成

- GUI exe 用 `#![windows_subsystem = "windows"]`，运行时不创建控制台窗口；日志写文件/面板，不依赖 stdout。
- exe 清单 `requireAdministrator`，双击即弹 UAC；CLI 单独一个 exe 保留控制台。
- 单实例：重复启动只激活已有窗口。
- 托盘用 Rust 侧 crate 实现（选型在实现阶段定），退出时确保 TUN 与托盘图标清理。
